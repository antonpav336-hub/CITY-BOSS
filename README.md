# CITY BOSS

3D life & business simulator for Android, built with Godot 4.

## Stage 1 — Foundation
- Third-person character controller with keyboard/gamepad and touch joystick input.
- Spring-arm camera with collision.
- Procedural starter apartment / courtyard greybox.
- Mobile HUD and interaction prompt.
- Local JSON save system.
- Android export workflow (requires export templates and Android signing configuration).

## Run
Open this folder in Godot 4.3+ and press **F6/F5** (main scene is `res://scenes/main/Main.tscn`).

Desktop controls: WASD move, Shift sprint, mouse drag to orbit, E interact.
Mobile: left virtual joystick, drag right side to look, Interact button.

This is the playable foundation; art assets and later business systems will be added in subsequent stages.
